# Project Card Editorial Rail Design

## Direction

Use the approved Editorial Rail direction for the project gallery: compact dark cards with a single emerald edge accent, clear top metadata, restrained icon treatment, and a stable bottom action area.

## Behavior

- Preserve all project data, filters, external links, and existing reveal transitions.
- Desktop cards stretch to a consistent row height without excessive empty space.
- Descriptions remain readable at a controlled line length.
- Technology badges stay grouped near the bottom of each card.
- Mobile cards collapse to natural height and remain single-column.
- Do not add new dependencies or new visual effects that increase scroll cost.

## Visual Rules

- Card radius: `rounded-2xl`, matching the existing soft panel language.
- Surface: dark tinted panel with a subtle border and one emerald left rail.
- Hover: translate upward by 1px and strengthen the rail/border only.
- Icon: smaller, quieter circular action marker aligned with the project heading.
